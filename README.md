# Particles

# Usage
`Mouse Click` to launch a short burst of colorful particles.

Click and drag across the screen to release an avalanche!

Press `ESC` to end the program.

# Building
### CMake
**IDE:** Simply click "Run."

**Console:** At the root of the project folder, run `cmake -B build`, then `cmake --build build`.

### g++
Requires installation of [SFML 2.6.2](https://www.sfml-dev.org/download/sfml/2.6.2/).
> **Warning:**
> NOT compatible with SFML 3.0.0 and above!

Use our provided makefile by running `make` at the root of the project folder.
